# Virt-Connector 0.1.5 — restore monitoring after Homebrew upgrades

Fix the `launchctl bootstrap` failure introduced in 0.1.4 when Homebrew runs LaunchAgent restoration inside its flight-step sandbox.

The signed package now restores monitoring from its installer script, running as the logged-in console user in that user's launchd session. The cask no longer needs a flight-step hook. Fresh installs, disabled or invalid configurations, installs to another volume, and installs without a console user do not start monitoring automatically.

If restoration fails, the package remains installed and prints a warning with the manual retry command, `virt-connector restore-agent`, instead of causing Homebrew to roll back the upgrade.

Rebuilt for arm64 with the macOS 27 SDK; minimum macOS 13. Signed, notarized, and stapled.
