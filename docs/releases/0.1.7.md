# Virt-Connector 0.1.7 — clearer monitoring status and safer confirmations

- Show monitoring status and the number of enabled devices in the menu bar menu. Distinguish disabled automation, unavailable configuration, shutdown preparation, and a completed shutdown request.
- Keep shutdown and monitoring recovery commands discoverable, with availability reflecting the current state. Explain when monitoring can safely resume after a canceled system shutdown.
- Remove the default button from shutdown and resume confirmations to avoid accidental Return-key activation. Support Escape to cancel and keyboard navigation between actions.
- Use native SF Symbol sizing and include monitoring status in the menu icon's accessibility label and tooltip.
- Correct the error title when monitoring cannot resume, and update Japanese and English menu wording.

Requires Apple Silicon and macOS 13 or later. Existing configuration and Shortcuts behavior are retained. Monitoring recovery does not cancel an operating-system shutdown request.

See the [GUI review](https://github.com/rioriost/Virt-Connector/blob/v0.1.7/docs/reviews/2026-09-21-apple-hig-gui.md) and [release validation](https://github.com/rioriost/Virt-Connector/blob/v0.1.7/docs/releases/0.1.7-validation.md) for coverage and remaining limitations.
