# Virt-Connector 0.1.4 — Homebrew 7 compatibility

Fix the deprecated `postflight` warning during Homebrew upgrades by migrating the cask to `postflight_steps`.

The new `restore-agent` packaging command restores the LaunchAgent only when an existing configuration enables monitoring. Configurations without an `enabled` key retain the previous enabled default. Missing, disabled, malformed, or invalid configurations are left untouched.

The hook resolves the account's home directory explicitly and declares its configuration, LaunchAgent, and log directories for Homebrew's install sandbox.

The signed macOS package is rebuilt with Apple Swift 6.4 and the macOS 27 SDK, notarized, and stapled. The minimum supported macOS version remains 13.

Reference: [Homebrew Cask Cookbook — flight steps](https://docs.brew.sh/Cask-Cookbook#stanza-flight_steps).
